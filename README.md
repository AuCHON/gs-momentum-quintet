# 动量五重奏（Momentum Quintet）

> 物理挑战赛参赛作品 —— 以「5 球单摆碰撞（牛顿摆）」为核心的纯 Web 物理弹射打靶游戏。
> 重力 · 碰撞 · 速度 · 惯性，一次全部呈现。

**直接双击 `index.html` 即可游玩**（零依赖、零外部资源、离线可玩，全部音效与画面均由代码程序化生成）。

## 一、玩法

一台五球牛顿摆实验台：

1. **抓球** —— 按住 1~4 号钢球中的任意一颗，**向右上方拖动**（1 号最靠右、质量最大）。抓第 n 号球就会拉起靠右的 n 颗球；越靠右链越长、弹速放大越高。
2. **松手** —— 钢球荡下，动量沿五球链逐级碰撞**向左**传递。
3. **断弦弹射** —— 最左端的 5 号铃球质量最轻（0.55），被撞后获得放大了的速度；当摆线张力 `T = m(g·cosθ + Lω²)` 超过阈值，琴弦绷断，铃球向左弹射出膛。**拉角太小张力不足，弦不会断（浪费一次弹丸）！**
4. **打靶** —— 弹丸受重力下坠，撞响左侧的钟阵、收集星星；撞墙/落地会反弹，可以一次飞行连击多个目标（×2、×3……最高 ×5 倍率）。弹丸接近目标时有短暂**慢镜头**（约 0.38×），命中瞬间清晰可见。

### 两个核心控制量

| 控制 | 物理含义 | 实测弹速范围 |
|---|---|---|
| 拉角 α（拖多高） | 能量守恒 v = √(2gL(1−cosα)) | — |
| 抓 1 号球（长链，质量大） | 链式速度放大 ×1.84 | 535 ~ 1587 px/s |
| 抓 2 号球 | ×1.62 | 472 ~ 1399 px/s |
| 抓 3 号球 | ×1.43 | 416 ~ 1234 px/s |
| 抓 4 号球（短链，整组） | ×1.26 | 576 ~ 1082 px/s |

> 注：上表实测口径为**拉角 25°~80°**；满拉角（约 110°）预估可达 ≈2000 px/s（瞄准仪表满值 1700 截断显示）。

### 模式与计分

- **闯关（12 关）**：每关有限弹丸、目标分数；钟 100/200/300 分（越小越远越值钱）、星星 350 分、连击倍率叠加。达标 1 星，更高分 2/3 星；星级随本局记录，开新挑战时重置（仅无尽最高分本地持久保存）。
  - **次数与锁定**：每关最多 **3 次结算机会，第 3 次为最终成绩**；达标通关或 3 次用尽即锁定本关。中途选关离开会**自动结算**当前关（计一次）；按 **R 重玩**与选关离开同规——已出手或已有得分时同样按自动结算计一次。结算弹窗点「🏠 主页」或「开新挑战」= 清空本局全部数据（含星级，仅无尽最高分持久保留）。
  - **终局**：**第 12 关结算即整局终局结算**（不论其他关卡是否玩过；含「结束结算」、选关离开与 R 重玩触发的一切结算），展示本局总分与全部明细。
- **手动结束**：任何时候点右上「结束结算」立即结束本关/本轮；结算弹窗显示**本关得分 + 本局总分 + 各关明细（得分/耗时）**（总分 = 本局已通关关卡得分与无尽模式本局最佳分之和，仅达标结算计入）。
  - 关卡递进：教学 → 远近 → 高低差 → 移动钟预判 → 越墙 → 峡谷落点 → 横移钟 → 双墙回廊连击 → 钟林连击 → 五重奏 → 精准乐器 → 终章·动量交响。
- **无尽模式**：初始 **10 发弹丸**；清空一轮所有钟进入下一轮（+2 弹丸 +150 分，每轮重新生成目标与星星），目标越来越远、越来越小、开始移动、出现障碍墙，直到弹丸耗尽，冲击最高分。
- 快捷键：**R** 重玩 · **M** 静音 · **Esc** 返回。鼠标与触屏均支持。

## 二、背后的物理（赛题四要素）

| 要素 | 在游戏中的体现 |
|---|---|
| **重力** | 单摆回复力 `ω' = -(g/L)sinθ`；弹丸抛体下坠 `a = g − k·v·\|v\|`（含 v² 空气阻力） |
| **碰撞** | 相邻球沿连心线的弹性碰撞（动量守恒 + 恢复系数 e≈0.985），碰后速度重新投影回摆弧切向（摆线约束）；弹丸撞墙 e=0.55、落地 e=0.42 + 摩擦、撞钟反弹可再连击 |
| **速度** | 拉开 α 角释放，能量守恒 `v = √(2gL(1−cosα))`；质量递减链 [2.4, 1.8, 1.35, 1.0, 0.55] 使每次"重球撞轻球"都放大速度（2m₁/(m₁+m₂) > 1） |
| **惯性** | 牛顿摆本体——动量沿球链传递不灭；轻拉张力不足弦不断，正是"惯性负载"的体现 |

物理内核与关卡数据全部经 Node 单元测试校准（见下文），弹速表、断弦阈值、每关可达性均有自动化断言。

## 三、运行方式与试玩地址

### 本地游玩（任意一种）

1. **最简单**：直接双击 `index.html`（纯前端，无需服务器）。
2. **HTTP 服务（赛题指定端口 9202 示例）**——在**游戏根目录**（`index.html` 所在目录）执行：
   ```bash
   python -m http.server 9202
   ```
   - 本机试玩：<http://127.0.0.1:9202>（端口可自选；局域网地址取决于运行机器的网络环境）

### 发布公网地址（可选）

- **Netlify Drop**（无需账号亦可）：打开 <https://app.netlify.com/drop>，把**游戏根目录**拖进去，立即得到公网地址。
- **GitHub Pages**：新建仓库 → 上传本目录全部内容 → Settings → Pages → 选择 main 分支 / root，地址为 `https://<用户名>.github.io/<仓库名>/`。
- **Vercel**：`npx vercel` 按提示操作，自动得到地址。

### 运行测试（可选，需 Node）

```bash
npm test                    # = 以下两条命令
node test/physics.test.js   # 物理内核：弹速校准表/断弦阈值/射程偏差/稳定性/关卡可达性/镜像方向/目标可见性
node test/ui.test.js        # UI 回归：状态机/结算计次/存档容错/渲染门控/输入命中（Node DOM 桩）
```

物理套件断言：质量阶梯单调、断弦阈值正确、抛体射程与理论值偏差 <9%、30 秒暴力仿真无 NaN/穿透、全部关卡目标可达且镜像后完整在画布内。

## 五、项目结构

```
.                       ← 游戏根目录（即交付包，双击 index.html 即玩）
├── index.html          入口（界面骨架、帮助、HUD）
├── style.css           深色实验室主题样式
├── js/
│   ├── physics.js      物理内核（纯逻辑，可 Node 测试）
│   ├── levels.js       12 个手工关卡 + 无尽模式生成器（含可达性约束）
│   ├── audio.js        WebAudio 程序化音效（五声音阶钟声）
│   ├── render.js       Canvas 渲染（网格实验室、金属球、琴弦张力、粒子）
│   └── game.js         状态机、输入、计分、存档、主循环
├── test/
│   ├── physics.test.js 物理单元测试与弹速校准表
│   └── ui.test.js      UI 回归测试（Node DOM 桩）
├── package.json        npm test 一键运行双测试套件
└── doc/reports/        AI 对抗审查报告归档
```

技术要点：Canvas 2D + 固定步长积分（240Hz 子步 + 4 轮碰撞迭代）；letterbox 自适应缩放；localStorage 仅持久保存无尽最高分（星级随本局重置）；无任何外部依赖（图片/音频/字体/库），源码约 105 KB。
