**Main Agent 决策（其余歧义项）**：

- O6（修复手段授权）：布局重排/卡片自适应缩放/文本省略号截断/媒体查询均可；HUD 长文案窄屏允许 ellipsis
- Y1（遮挡口径）：**同屏同显的元素不得互相遮挡**（panel-play 与 meter 矮窗重叠、hint 与 meter 窄屏重叠均需修）
- 浮层明细列表/说明面板的**组件内部滚动**可接受（既有设计）；"不滚动"口径指页面级滚动
- O3/O4/O5（Fullscreen API 触发时机/Esc 冲突/iOS 回退）：随 R1 决策全部消解（N/A）
- Y3：保留 user-scalable=no（拖拽操作需要），小屏兜底走 .screen 滚动

**验收视口矩阵**：1920×1080、1366×768、1280×720（必须无页面滚动、无裁切、无同显遮挡、无大片空带）；768×1024 尽量；390×844 允许屏内滚动但不得裁切。
